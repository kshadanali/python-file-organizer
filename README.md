# 📁 Python File Organizer

A simple Python program that automatically organizes files into different folders based on their file type.

## Features

- Organizes images
- Organizes documents
- Organizes videos
- Organizes music
- Uses Python `os` and `shutil` modules

## Technologies

- Python 3
- OS Module
- Shutil Module

## How to Run

Run this command:

python file_organizer.py

Then enter the path of the folder you want to organize.
